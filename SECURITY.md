# Security policy

## Reporting a vulnerability

Report it privately: use **Report a vulnerability** on this repository's Security tab, or reach the
owner through his GitHub profile. Please do not open a public issue for it.

Never post a key, a token, a password or a `.env` file in an issue, a pull request or a report. If
you have found one exposed, say where it is, not what it is.

## Scope

Manjuel is the ground and the record, run on the owner's PC against local Ollama. Security-relevant
areas: the record's hash chain, the shell gate and the approval cards (no write, commit or push
without the owner's click), the semantic index's shield (no secrets, no client ground), and the
handling of `.env`, which is honoured and never printed, copied, committed or indexed.
