## When

- **Action Keyword:** when
- **Description:** Lists what ran in a WINDOW OF TIME, read from the transcript stamps in logs/. Use for "what ran yesterday", "what did we do this week", "what happened on 2026-09-01", "what have we been doing lately". Understands today, yesterday, this week, this month, recently, "the last N days", and an exact YYYY-MM-DD. For a numbered sitting use the `sitting` skill instead — a sitting is a unit of work, a period is a stretch of clock.
- **Parameters Needed:** <content>The period, e.g. yesterday, this week, or 2026-09-01.</content>
- **Says:** what ran yesterday, what did we do this week, what have we been doing lately, what ran today, what happened on, what ran this week, what ran last week, what have we been up to, what ran between, ran between, we do yesterday, we do today, we do last night, ran yesterday, ran today, ran this week, ran last week, ran this month, ran lately, ran recently, ran on, did yesterday, did today, did this week, did lately, did recently, happened yesterday, happened today, happened this week, happened last night, happened on, happened lately, happened recently, been doing lately, been doing recently, went on yesterday, went on this week
